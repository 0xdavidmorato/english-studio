English Studio

Projeto "english-studio" — scaffold inicial criado a partir do modelo do repositório `tangle` com o objetivo de desenvolver um site e app mobile para estudar e treinar inglês.

O repositório local contém a estrutura arquitetural (src, app, docs, configurações Next/TypeScript) copiada do modelo. Não serão feitos pushes ao repositório remoto sem autorização explícita.

Tarefas iniciais sugeridas:
- Revisar e extrair componentes de UI reutilizáveis (src/ui)
- Ajustar rotas e conteúdo para lições, quizzes e exercícios em inglês
- Criar repositório remoto no GitHub (opcional) e atualizar package.json
- Scaffold do app mobile (Expo) ou planejamento de monorepo
